# About Me: Trivia Mini Project

## Objective
A short, 10 question trivia game meant for one player.

## Features
### Required Functions:

- Welcome Screen
- Question Display
- Game Flow
- Score Tracking
- Results Screen
  - Displays a score / question amount along with a %.

### Extra Functions:
- Question Categories
  - ECE questions
  - Deadlock (a video game) questions
- Timer per Question
  - 15-second timer per question
- UI Design
  - Random colors for answer options
  - Results screen colored based on score
